🩺 Diabetes Prediction using KNN Algorithm
📌 Project Overview

This project predicts whether a person is diabetic or not using the K-Nearest Neighbors (KNN) algorithm.
It uses medical attributes like glucose level, BMI, age, etc., to make predictions and helps in early detection of diabetes.

🎯 Objectives
Build a classification model using KNN
Analyze medical data for patterns
Evaluate model performance
Create a simple prediction system

📊 Dataset
PIMA Indians Diabetes Dataset
Features:
Pregnancies
Glucose
Blood Pressure
Skin Thickness
Insulin
BMI
Diabetes Pedigree Function
Age

🧠 Model Used
🔹 K-Nearest Neighbors (KNN)
A supervised machine learning algorithm
Classifies data based on the majority class of nearest neighbors
Distance metric used: Euclidean Distance
Value of K: 7

⚙️ Technologies Used
Python
NumPy
Pandas
Matplotlib 
Scikit-learn
